Data Environment

The Data Environment has many components that need to function cohesively in order to enable scientific discovery. Among those, here is a set of components vastly used by the Heliophysics community:

Data Formats

  • FITS
  • CDF
  • NetCDF
  • HDF5
  • IAGA-2002
  • CSV RFC 4180

Metadata

  • SPASE
  • ISTP Metadata Guidelines
  • DOI (see also Datacite)

API

  • HAPI
  • TAP
  • EPN-TAP
  • DAS2

Tools

  • PyHC libraries (e.g., SunPy, pySPEDAS, SolarMACH)
  • Jhelioviewer and Helioviewer
  • Autoplot
  • SPEDAS
  • CDAWeb
  • SSCweb orbits
